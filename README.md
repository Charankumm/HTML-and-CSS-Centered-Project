# 🎯 Centered Div with HTML & CSS

This project showcases a simple and effective way to **center a `<div>` both vertically and horizontally** using modern CSS Flexbox techniques.

## 📦 Overview

The main objective of this project is to demonstrate how to center content within the browser window using:

- `display: flex`
- `justify-content: center`
- `align-items: center`

This is a very common layout technique used in web development.

## ✨ Features

- Fully responsive centered layout
- Clean, minimal design
- Styled box with shadows and rounded corners
- Uses separate CSS file for styling

## 📁 File Structure
centered-div/
├── index.html
├── styles.css
└── README.md

## 💡 How It Works

- The `body` is made a flex container with `display: flex`
- `justify-content: center` aligns the child element (`.centered-box`) horizontally
- `align-items: center` aligns it vertically
- `height: 100vh` ensures the container fills the entire viewport
